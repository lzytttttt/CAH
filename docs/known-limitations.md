## 2. 工程限制

- 单后端进程、单用户；SQLite WAL + 本地对象目录，不含 Redis/消息队列/分布式租约。多进程并发写同一数据目录不受支持。
- 事件不自动裁剪（P0 数据量可接受）；长时间运行需要归档策略（索引已就绪，未实现清理任务）。
- 备份为“WAL checkpoint 后复制数据库 + 对象清单”的服务层能力（storage.backupTo），未实现定时调度。
- 性能：已实测 1000 行确定性清洗 5.4 ms、5,000 事件快照恢复 33.9 ms（目标 <2 s）；**点击 p95、动画帧率、30 分钟内存未测量**，不宣称通过。
- 浏览器兼容性以现代桌面 Chromium 为主；Safari/Firefox 未专项验收。
- Windows 下 0600 文件权限由操作系统决定；本地单用户威胁模型依赖回环监听 + 会话 + Origin 校验。
- URL 策略不做 DNS 解析；DNS rebinding/内网解析需部署层 egress 策略。

## 3. 安全边界（必须理解）

- 服务默认只监听回环地址；不要直接暴露到公网或不可信局域网。
- 本地会话令牌文件 `data/session-token` 等同密码，勿提交、勿分享。
- UI 保存凭据需要 `CA_CREDENTIALS_MASTER_KEY`；未配置时拒绝保存明文凭据。凭据只在后端解析，前端只见掩码/状态。
- 工具输入、模型输出、导入任务包均视为不可信内容；导入包不会自动激活配方或外部连接；ZIP 导入校验路径/大小/哈希。

## 4. 数据与演示声明

- `scenarios/cognitive-atrium/` 全部为合成演示数据；商业价值、市场规模、客户采纳等结论均为**待验证假设**，不得作为真实结论引用。
- Demo 工作区为固定夹具（已接受架构、待审阅清洗草稿、被硬约束冲突阻塞的计划预览、一次失败尝试、一个 validated 配方），只读、不调用真实模型；Live 失败不会回退为 Demo 结果。
- Live 与 Demo 物理隔离（独立 SQLite + 对象目录）；切换模式在有活动执行时被拒绝，等待输入/审阅中的运行会被保留而不是被静默终止。
