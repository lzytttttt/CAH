## 2. 工程限制

- 单后端进程、单用户；SQLite WAL + 本地对象目录，不含 Redis/消息队列/分布式租约。多进程并发写同一数据目录不受支持。
- 事件回放按任务读取并重建快照；当前不裁剪历史事件（P0 数据量下可接受），长时间运行需要归档策略（已在存储层预留索引，未实现自动清理）。
- 备份为“WAL checkpoint 后复制数据库 + 对象清单”的手动/脚本方式；未实现定时备份调度。
- 部分性能目标（点击 p95、动画帧、5000 事件恢复、1000 行清洗耗时、30 分钟内存）尚无带环境记录的实测数据；测量结果将在验收报告中补充，未测量项不宣称通过。
- 浏览器兼容性以现代桌面 Chromium 为主；Safari/Firefox 未做专项验收。
- Windows 下文件权限（0600）由操作系统决定；本地单用户威胁模型下依赖回环监听 + 会话 + Origin 校验。

## 3. 安全边界（必须理解）

- 服务默认只监听回环地址；不要直接暴露到公网或不可信局域网。
- 本地会话令牌文件 `data/session-token` 等同密码，勿提交、勿分享。
- UI 保存凭据需要 `CA_CREDENTIALS_MASTER_KEY`，主密钥与数据库分开保存；未配置时拒绝保存明文凭据。
- 工具输入、模型输出、导入任务包均视为不可信内容；导入包不会自动激活配方或外部连接。
