# 用户操作指南

## 1. 首次配置模型（Live）

1. 打开工作台，右上角设置 → 模型连接 → 新建连接：填写名称、服务地址（baseURL）、模型名、凭据引用。
2. 先点击“测试连接”第一步（鉴权 + 基础文本）。
3. 如需确认流式/工具/结构化输出/usage，再次点击能力探测并确认会产生少量费用；每项显示 verified / unsupported / unknown / error。
4. 凭据不会显示在前端；若环境变量方式不适用，可在设置中保存凭据（需服务端配置 `CA_CREDENTIALS_MASTER_KEY`）。

## 2. 新建任务与导入资料

1. “新建任务”：填写标题、意图、交付物标题；选择内置模板或自定义 1–8 个模块（名称、类型 markdown/JSON/CSV、依赖、验收标准）。
2. 导入资料：支持 UTF-8 TXT、Markdown、JSON、CSV；单文件 ≤10MiB，单任务 ≤50MiB。不支持的类型会被明确拒绝，不会伪装成空文件。
3. 资料只登记，不会自动全部进入模型上下文；发起意图时可选择参与的资料。

## 3. 在模块上提出意图

1. 点击中心交付区的模块，输入意图（可粘贴长文本）。
2. 系统展示计划预览：目标骨架、输入版本、步骤、工具范围、预算与**真实风险数量**。
3. 有硬约束冲突/缺失信息时先处理（补充证据、修改约束、缩小范围）；未处理不能提交。
4. 简单只读且输出明确的操作可直接执行；执行阶段显示真实工具调用、模型调用与检查点。

## 4. 局部修复

- 出现阻塞时展示 1–3 张修复卡（选择 / 补充文本 / 绑定资料 / 确认映射 / 排除条目），标明受影响字段与步骤。
- 补齐后只重跑受影响的后续步骤，已完成且输入未变的步骤复用。
- 取消本次修复会保留已接受成果。

## 5. 审阅与接受

- 进入“待审阅”：查看章节差异、证据引用、L0–L4 验证结果与剩余人工判断项。
- 接受全部 / 按章节接受（限稳定 ID 且验证允许）；提交时再次检查基线与验证报告有效性。
- 版本冲突时双方内容保留，可查看差异、重新生成或人工合并；恢复旧版本会创建内容相同的新版本并触发下游 stale。

## 6. 保存与复用配方

- 成功的确定性支线可“保存为配方”：审阅服务端提取的步骤 → 运行测试（原始 / 新数据 / 非法输入）→ 注册 validated。
- 用新数据运行：显示 deterministic 与 0 次 LLM 调用、输出哈希与行数；非法输入被拒绝。
- 配方失效（工具/prompt/规则变化）会标记 stale，需要重新测试。

## 7. 高台综合成果

- 右上高台展示可产生的综合成果及所需输入；缺少输入时显示缺少项并高亮相关模块。
- 输入满足后仍需真实生成、验证、审阅和接受；未接受草稿不会解锁正式综合。
- 上游版本变化后综合成果标记 stale。

## 8. 恢复与导出

- 刷新/断线：后端继续运行，重连读取快照并续传事件；不重复发起 Run。
- 关闭页面：默认后端继续（受预算限制）；可设置“离开时暂停”。
- 服务重启：从检查点恢复；强制终止的运行标记 INTERRUPTED 并列出需核对的调用。
- 导出：Markdown / JSON / CSV / 任务包（默认不包含原始资料；导入后提示重新绑定，配方不自动执行）。

## 9. 键盘与无障碍

- Tab / Shift+Tab 遍历操作；Enter 执行主操作；Escape 关闭局部面板并保留草稿；Alt+↑/↓ 切换层级（也可点击可见按钮）。
- 状态均有文字标签，不只靠颜色；`prefers-reduced-motion` 下关闭倾斜/缩放/晃动/粒子，业务步骤不变。
- 宽度 <1024 时退化为有顺序的模块视图；200% 缩放下核心按钮与文字仍可访问。

## 10. CLI 快速参考

见 [README](README.md#cli)；等待人工输入时退出码为 2 并输出 blocker 与可选项，使用 `run resolve` 继续。
